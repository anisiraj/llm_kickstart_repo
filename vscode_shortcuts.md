# ⚡ WINDOW & PANEL NAVIGATION — Quick Reference

## Open / Toggle Panels

| What | Shortcut |
|------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Toggle left sidebar on/off | `Ctrl + B` |
| Toggle right sidebar on/off | `Ctrl + Alt + B` |
| Toggle bottom panel on/off | `Ctrl + J` |
| Toggle terminal | `Ctrl + `` ` `` ` |
| Maximize / restore panel | `Ctrl + K   Z` (zen) or drag |

## Switch Between Open Editor Tabs / Groups

| What | Shortcut |
|------|----------|
| Next open tab | `Ctrl + Tab` |
| Prev open tab | `Ctrl + Shift + Tab` |
| Focus editor group 1 | `Ctrl + 1` |
| Focus editor group 2 | `Ctrl + 2` |

| Split editor (open side by side) | `Ctrl + \` |

| Close current tab | `Ctrl + W` |

# TOP ★ PICKS — Biggest Mouse Savers

| Shortcut | Why it saves the most |
|----------|-----------------------|
| `Ctrl + P` | Open any file instantly — no clicking through the Explorer tree |
| `F12` | Jump to definition without right-clicking |
| `Alt + Left / Right` | Navigate back/forward through cursor history — replaces clicking tabs |
| `Ctrl + D` | Select + edit next occurrence inline — replaces find→click→edit loops |
| `Ctrl + Shift + L` | Rename every occurrence at once — no find/replace dialog needed |
| `Ctrl + 1 / 2 / 3` | Switch between split editor panes without clicking |
| `Ctrl + B` | Collapse sidebar to reclaim screen space instantly |
| `Ctrl + .` | Fix errors without moving to the mouse gutter icon |
| `Alt + Up / Down` | Reorder lines without cut/paste |
| `Ctrl + /` | Comment out a block without reaching for the menu |
| `Ctrl + \`` ` `` ` | Open/close terminal without clicking the bottom bar |
| `Ctrl + Shift + P` | Run any command by name — replaces almost all menu navigation |
