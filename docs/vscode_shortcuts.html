VSCode — Essential Shortcuts (Linux)

Navigate Between Panels & Windows
Open any file (fuzzy search) Ctrl + P
Command Palette Ctrl + Shift + P
Toggle left sidebar Ctrl + B
Toggle bottom panel Ctrl + J
Toggle terminal Ctrl + `
Focus editor (from anywhere) Ctrl + 1
Switch Sidebar View
Explorer (files) Ctrl + Shift + E
Search in files Ctrl + Shift + F
Source Control (git) Ctrl + Shift + G
Switch Bottom Console
Terminal Ctrl + `
Problems Ctrl + Shift + M
Output Ctrl + Shift + U
Debug Console Ctrl + Shift + Y
Next terminal tabCtrl + PageDown
Prev terminal tabCtrl + PageUp
Switch Editor Tabs
Cycle open tabs Ctrl + Tab
Focus pane 1 / 2 / 3 Ctrl + 1 / 2 / 3
Split editor side by sideCtrl + \
Close current tab Ctrl + W
Editing (Biggest Time Savers)
Go to definition F12
Go back / forward Alt + ← / →
Select next occurrence Ctrl + D
Select ALL occurrences Ctrl + Shift + L
Move line up / down Alt + ↑ / ↓
Toggle comment Ctrl + /
Quick fix / suggestions Ctrl + .
Drill these first: Ctrl+P (open file)  ·  Ctrl+` (terminal)  ·  Ctrl+1 (back to editor)  ·  Ctrl+Tab (cycle tabs)  ·  Ctrl+Shift+P (any command)
