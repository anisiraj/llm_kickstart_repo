🦥 Unsloth + LoRA / QLoRA — End-to-End Fine-Tuning One-Pager

🧩 LoRA vs QLoRA — What to Pick
MethodVRAMSpeedWhen to use
Full FT80GB+FastestMany GPUs, max quality
LoRA~20GBFast1× A100, good quality
QLoRA~6GBSlowerSingle consumer GPU / Colab
LoRA freezes the base model and adds small rank-decomposed adapter matrices (A×B) to attention layers. Only adapters are trained — <1% of params. QLoRA = QLoRA quantizes the frozen base to 4-bit NF4, trains LoRA adapters in bf16. 33% less VRAM than LoRA, ~39% slower. Unsloth: 2× faster training, 60% less VRAM via custom Triton CUDA kernels. Single-GPU only.

① Load Model (QLoRA = 4-bit)
from unsloth import FastLanguageModel
import torch

model, tokenizer = FastLanguageModel.from_pretrained(
    model_name = "unsloth/Meta-Llama-3.1-8B-bnb-4bit",
    max_seq_length = 2048,   # max tokens per sample
    load_in_4bit  = True,    # QLoRA (False = LoRA 16-bit)
    dtype         = None,    # auto-detect bf16/fp16
)
# Popular 4-bit checkpoints (pre-quantized, fast download):
# unsloth/Meta-Llama-3.1-8B-bnb-4bit
# unsloth/Qwen2.5-7B-bnb-4bit
# unsloth/mistral-7b-v0.3-bnb-4bit
# unsloth/gemma-2-9b-bnb-4bit
② Attach LoRA Adapters
model = FastLanguageModel.get_peft_model(
    model,
    r              = 16,    # rank: 8/16/32/64. Higher=more params
    lora_alpha     = 16,    # scaling: keep = r (or 2×r for aggressive)
    lora_dropout   = 0,     # 0 is optimal per Unsloth
    target_modules = ["q_proj", "k_proj", "v_proj",
                      "o_proj", "gate_proj",
                      "up_proj", "down_proj"],
    use_rslora     = True,  # rank-stabilised LoRA (recommended)
    use_gradient_checkpointing = "unsloth",  # saves VRAM
    bias           = "none",
    random_state   = 42,
)
# Result: ~42M trainable / 8B total = 0.52%
③ Prepare Dataset (ChatML format)
from datasets import load_dataset
from unsloth.chat_templates import get_chat_template

# Apply chat template to tokenizer
tokenizer = get_chat_template(
    tokenizer,
    chat_template = "chatml",  # or "llama-3", "mistral"
    mapping = {"role":"from", "content":"value",
               "user":"human", "assistant":"gpt"},
)

def apply_template(examples):
    return {"text": [
        tokenizer.apply_chat_template(m, tokenize=False,
            add_generation_prompt=False)
        for m in examples["conversations"]
    ]}

dataset = load_dataset("mlabonne/FineTome-100k", split="train")
dataset = dataset.map(apply_template, batched=True)
# Your own data: Dataset.from_dict({"conversations": [...]})
④ Train with SFTTrainer
from trl import SFTTrainer
from transformers import TrainingArguments
from unsloth import is_bfloat16_supported

trainer = SFTTrainer(
    model              = model,
    tokenizer          = tokenizer,
    train_dataset      = dataset,
    dataset_text_field = "text",
    max_seq_length     = 2048,
    packing            = True,   # pack short samples → faster
    args = TrainingArguments(
        output_dir                  = "output",
        num_train_epochs            = 1,
        per_device_train_batch_size = 8,
        gradient_accumulation_steps = 2,    # eff. batch=16
        learning_rate               = 3e-4,
        lr_scheduler_type           = "linear",
        warmup_steps                = 10,
        optim                       = "adamw_8bit",
        weight_decay                = 0.01,
        fp16 = not is_bfloat16_supported(),
        bf16 = is_bfloat16_supported(),
        logging_steps               = 10,
        seed                        = 42,
    ),
)
trainer.train()
⑤ Inference (after training)
# Switch to fast inference mode
FastLanguageModel.for_inference(model)

from transformers import TextStreamer

messages = [{"from": "human",
             "value": "Explain transformers in 2 sentences."}]

inputs = tokenizer.apply_chat_template(
    messages,
    tokenize               = True,
    add_generation_prompt  = True,
    return_tensors         = "pt",
).to("cuda")

streamer = TextStreamer(tokenizer)
_ = model.generate(
    input_ids        = inputs,
    streamer         = streamer,
    max_new_tokens   = 256,
    use_cache        = True,
    temperature      = 0.7,
    do_sample        = True,
)
⑥ Save — 3 Options
# Option A: LoRA adapters only (smallest, ~100MB)
model.save_pretrained("lora_model")
tokenizer.save_pretrained("lora_model")

# Option B: Merged 16-bit (best quality, ~16GB)
model.save_pretrained_merged("merged_model", tokenizer,
    save_method = "merged_16bit")
# Push to HF Hub
model.push_to_hub_merged("username/MyModel", tokenizer,
    save_method = "merged_16bit")

# Option C: GGUF (for Ollama / LM Studio / llama.cpp)
quants = ["q4_k_m", "q8_0", "q5_k_m"]
for q in quants:
    model.push_to_hub_gguf("username/MyModel-GGUF",
                            tokenizer, q)

# Run locally with Ollama after GGUF export:
# ollama run hf.co/username/MyModel-GGUF
⚠️ Always save tokenizer alongside model. Merged model = no adapter needed at inference.
⚡ Full Workflow in One Glance
① from_pretrained (4-bit) → ② get_peft_model (LoRA) → ③ load + map dataset → ④ SFTTrainer.train() → ⑤ for_inference + generate → ⑥ save / push to Hub
GPU time (100k samples, 1 epoch): A100 40GB ≈ 4h45m  |  L4 ≈ 19h  |  T4 (free Colab) ≈ 47h   |   Trainable params: r=16 → ~42M / 8B = 0.52%   |   VRAM: QLoRA 8B ≈ 5.5GB  |  LoRA 8B ≈ 14GB
