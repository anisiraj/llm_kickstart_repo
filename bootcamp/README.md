# Open Bootcamp Exercise — Starter Data

These are **placeholder files** for the bootcamp exercise described in the handbook.

| File | Purpose | Replace with |
|------|---------|--------------|
| `company_schema.sql` | Database schema (10 tables) | Your org's actual schema (anonymized) |
| `knowledge_dump.txt` | Internal wiki / Confluence export | Your org's docs, runbooks, SOPs |
| `text_to_sql_pairs.jsonl` | Natural language → SQL pairs (16) | More pairs from your real queries |
| `sql_to_text_pairs.jsonl` | SQL → natural language explanation (10) | Explanations of your common queries |

**How to use:** Follow the workflow in the handbook → "Open Bootcamp Exercise" section.
